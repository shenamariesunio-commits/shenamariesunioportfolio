# Shena Marie Sunio — Portfolio

GitHub Pages-ready portfolio draft for Shena Marie Sunio, Social Media & Marketing Creative.

## Files
- `index.html` — homepage
- `project-social-media.html` — social media case study placeholder
- `project-ecommerce.html` — e-commerce case study placeholder
- `project-branding.html` — branded content case study placeholder
- `project-ads.html` — paid media case study placeholder
- `assets/` — uploaded branding references

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The site uses Google Fonts, so an internet connection is needed for the typography to load as designed.
